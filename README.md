# boltbolt

Bolt encode/decode helpers for bolt payloads in pipelines.

**Site:** https://theworker02.github.io/boltbolt/

## Install / run

```bash
git clone https://github.com/theworker02/boltbolt.git
cd boltbolt
node src/cli.js
node --test
```
